तुम अब तक `npx tsc -p tsconfig.json --noEmit` चलाकर "0 errors" देखते रहे हो।

```bash

NODE_OPTIONS="--max-old-space-size=3072" npx tsc -p tsconfig.frontend.json --noEmit
```

## 🔍 एक पक्का सुराग — TS2307 वालों की जड़
`m13-automation/WorkflowEngine.ts` यह import करता है:
```ts
import { Logger } from '../../../m01-foundation/src/Logger';
```
**वो रास्ता मौजूद ही नहीं है।** M01 में `src/Logger` नाम की कोई चीज़ नहीं।
सही जगह देखो: `@/common/logging/logger`. बाक़ी 19 TS2307 भी शायद इसी तरह के हैं —
पहले सारे import रास्ते जाँचो, इससे एक झटके में बहुत सारे errors गिरेंगे।
