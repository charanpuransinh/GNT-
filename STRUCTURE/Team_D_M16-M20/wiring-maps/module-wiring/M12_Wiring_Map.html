📋 Contract Notes & Lock Rules

🔒 Auth: x-tenant-id + JWT Bearer
🔒 Validation: Zod schemas FE & BE
🔒 Rate Limit: 100 req/min per tenant
🔒 Pagination: ?page=1&limit=20
🚫 No Direct Access: M12 NEVER accesses M11 DB
✅ Public API Only: Cross-module via Redis
📦 DTOs: { success, data, meta }
👤 GDPR: Employee data encrypted at rest
