📡 API Contracts (REST + WS)

GET/api/v1/m13/workflows
POST/api/v1/m13/workflows
PUT/api/v1/m13/workflows/:id

↳ Request: { name, trigger, actions[], status } | Response: WorkflowDTO[]
GET/api/v1/m13/triggers

GET/api/v1/m13/schedules

GET/api/v1/m13/notifications/templates
POST/api/v1/m13/notifications/send
↳ Request: { channel, templateId, recipients[], variables } | Response: { messageId, status }
GET/api/v1/m13/approvals
POST/api/v1/m13/approvals
PATCH/api/v1/m13/approvals/:id/action

↳ Response: ExecutionLogDTO[] with pagination
WS/ws/m13/events

📋 Contract Notes & Lock Rules

🔒 Auth: All endpoints require x-tenant-id + JWT Bearer token
🔒 Validation: Zod schemas on both FE (forms) & BE (routes)
🔒 Rate Limit: 100 req/min per tenant on mutation endpoints
🔒 Pagination: All LIST endpoints: ?page=1&limit=20&sort=-createdAt
🚫 No Direct Access: M13 NEVER accesses M07/M10/M12 DB directly
✅ Public API Only: Cross-module via Event Bus (Redis) or Public Service Layer
📦 DTOs: All responses wrapped in { success, data, meta }
🔄 WS Reconnect: Auto-reconnect with exponential backoff (max 5 retries)
