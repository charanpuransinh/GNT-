📋 Contract Notes & Lock Rules

🔒 Auth: x-tenant-id + JWT Bearer
🔒 Validation: Zod schemas + file type check
🔒 File Limit: Max 50MB per upload
🔒 Pagination: ?page=1&limit=20
🚫 No Direct Access: M14 NEVER accesses other module DBs
✅ Public API Only: Cross-module via Redis
📦 DTOs: { success, data, meta }
📤 Async: Heavy imports run in background queue
